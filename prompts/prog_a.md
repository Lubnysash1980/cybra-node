# Програма A
Мова: Python 3 (тільки stdlib)
Призначення: CLI-утиліта для підрахунку балансу з CSV-файлу транзакцій.
Вимоги:
- аргументи: --input FILE.csv, --month YYYY-MM
- виводить: total_in, total_out, balance
- обробляє порожні файли без падіння
- без зовнішніх залежностей
Виводь ЛИШЕ код файлу. Без markdown, без пояснень, без ```.
